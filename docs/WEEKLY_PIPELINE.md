# Serialized Fiction Production Pipeline

## Weekly Output

Every week:
- 5 vertical episodes, each 60 to 90 seconds.
- 1 YouTube compilation, 8 to 12 minutes.
- 5 episode captions.
- 5 pinned comments.
- 1 community post teasing the next turn.

## Weekly Schedule

### Monday: Story Room

Goal: plan the week before generating anything.

Tasks:
- Pick the week's central mystery.
- Define the five episode cliffhangers.
- Decide what changes emotionally for the main character.
- Write one sentence for each episode.
- Choose the recurring visual motif for the week.

AI prompt:
```text
Plan five 60-90 second episodes for an Afro-futurist mystery thriller series.

Series premise:
A Lagos delivery rider has a phone that receives text messages from tomorrow.

Rules:
- Each episode must have one impossible message.
- Each episode must end with a cliffhanger.
- Each episode must include a specific consequence.
- Avoid gore, real disasters, public figures, and copyrighted characters.
- Make the episodes connected, not random.

Return:
episode title, hook, moral choice, consequence, cliffhanger.
```

### Tuesday: Scripts

Goal: write all five narration scripts.

Tasks:
- Draft 5 scripts.
- Keep each script 150 to 220 words.
- Make each first line strong enough for TikTok and Shorts.
- Add caption-safe line breaks.
- Add visual direction every 10 to 15 seconds.

Script quality check:
- Can someone understand the story without reading the description?
- Does something change?
- Is the cliffhanger specific?
- Is the episode original enough to stand alone?

### Wednesday: Voice and Visual Prompts

Goal: create asset instructions.

Tasks:
- Record or generate narration.
- Create 6 to 8 image/video prompts per episode.
- Use consistent character descriptions.
- Generate visuals in a consistent style.
- Save outputs into episode folders.

Recommended tools:
- Voice: your voice, ElevenLabs, or another licensed AI voice.
- Images: ChatGPT image generation, Midjourney, Leonardo, Ideogram, or similar.
- Motion: Sora, Runway, Luma, Pika.
- Edit: CapCut, Descript, DaVinci Resolve, Premiere, or Final Cut.

### Thursday: Edit Episodes

Goal: finish five vertical episodes.

Edit recipe:
- 0:00 impossible hook
- 0:03 character reaction
- 0:10 context
- 0:25 deadline
- 0:40 choice
- 0:55 consequence
- 1:05 cliffhanger

Editing rules:
- Use captions for every spoken line.
- Use sound design: phone buzz, rain, traffic, low pulse.
- Move visually every 2 to 4 seconds.
- Avoid long static slides.
- Keep each video above 60 seconds for TikTok reward eligibility.
- Export 1080x1920 or higher.

### Friday: Publish and Package

Goal: release consistently.

Posting:
- TikTok first.
- YouTube Shorts second.
- Instagram Reels optional third.

Metadata:
- Include "fictional story" in the description or caption.
- Use 3 to 6 relevant hashtags.
- Pin a comment teasing the next episode.

### Saturday: Compilation

Goal: turn Shorts into a YouTube long-form asset.

Tasks:
- Combine episodes 1 to 5.
- Add 5-second intro.
- Add chapter cards.
- Add 1 to 2 seconds of ambience between episodes.
- Export 1920x1080 or 1080x1920 depending on channel strategy.

Recommended:
- Use 16:9 for YouTube long-form once you can afford extra visuals.
- Use vertical compilation at first to move faster.

### Sunday: Review

Track:
- 3-second hold
- average watch time
- completion rate
- rewatches
- comments asking for episode 2
- followers gained per episode
- saves and shares

Decision rules:
- If the first 3 seconds are weak, rewrite hooks.
- If people drop after 20 seconds, shorten setup.
- If comments ask questions, answer them in the next episode.
- If one visual style performs better, standardize it.

## Anti-Spam Quality Bar

Before posting, check:
- Did a human write or meaningfully revise the story?
- Is this episode materially different from the last one?
- Are the visuals directed for this exact story?
- Does the narration have emotion and pacing?
- Is there a real scene, not just text over random images?
- Does the ending create story curiosity without lying?

If any answer is no, revise before publishing.
