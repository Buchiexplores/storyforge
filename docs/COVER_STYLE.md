# Cover Style Guide

## Two-layer cover system

Storyforge builds episode covers in **two layers**:

1. **AI background** — A vertical 9:16 scene plate generated by OpenAI, fal.ai, or a local fallback image. The prompt explicitly forbids typography; it only paints atmosphere, foreground props, and composition that leave room for titles.
2. **Local typography** — Grades, series title stack, episode badge, hook callout, episode title, rain/glitch/scratch effects, and color accents are composited in Python (`tools/cover_styles.py`) onto the base PNG.

Outputs land in the episode `assets/exports/` folder:

- `{output_slug}_cover_base.png` — raw background plate
- `{output_slug}_cover.png` — final composed cover used in the render intro

The slug comes from `scenes.json` → `output_slug` (via `episode_output_slug()`).

---

## Quick start

List styles for your series template:

```bash
python3 tools/generate_episode_assets.py --list-cover-styles
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 --list-styles
```

Generate cover during asset pipeline:

```bash
python3 tools/generate_episode_assets.py --series series/my_series --episode episode_01 --cover
```

Regenerate or iterate on cover only:

```bash
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 \
  --style thriller_neon_rain --compose-only
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 \
  --style sci_fi_cyan --force-background --save-style
```

## Style resolution order

The active design style id is resolved in `resolve_cover_style_id()` (first match wins):

1. **`scenes.json`** → `cover.design_style` (per-episode override)
2. **`series_config.yaml`** → `cover.default_design_style` (series-level override; wins over template defaults when set)
3. **Style template** → `cover.default_design_style` in `config/style_templates/<style_template>.yaml` (merged into series settings when series config does not override)
4. **`config/cover_styles.yaml`** → `default_for_template[<style_template>]` (fallback when no `default_design_style` is present in merged settings)

If nothing matches, the pipeline falls back to `thriller_neon_rain`.

## Style anatomy

Every entry under `styles:` in `config/cover_styles.yaml` controls local composition:

| Field | Role | Known values |
|-------|------|--------------|
| `grade` | Color grade, vignette, and overlay treatment on the base image | `rain_neon`, `cold_fog`, `warm_glow`, `high_contrast`, `soft_wash`, `sepia_dust`, `pastel`, `terminal_scan`, `noir_shadow` |
| `series_layout` | How the series title stacks at the top | `stacked_glitch`, `stacked_clean`, `single_impact`, `minimal_top` |
| `title_layout` | Episode title treatment at the bottom | `brush_accent`, `distressed_stack`, `uniform_impact` |
| `badge_style` | Episode / part badge look | `red_episode`, `cyan_episode`, `gold_episode`, `magenta_episode`, `outline_minimal` |
| `hook_style` | Left hook callout (uses `hook_lines` / `hook_highlight` from scenes) | `handwritten_arrow`, `block_left`, `none` |
| `colors` | Hex palette: `accent`, `accent2`, `title`, `badge_fill`, `hook_highlight`, `part_outline`, `part_text` | Per-style |
| `effects` | Post overlays on the composed poster | `rain`, `glitch`, `scratch` (booleans) |

The `grade` also steers the **background prompt mood** in `cover_background_prompt()` (e.g. rainy neon vs cold fog vs warm glow).

## Per-episode cover fields (`scenes.json`)

```json
"cover": {
  "design_style": "thriller_neon_rain",
  "series_title": "Your Series Title",
  "episode_number": 1,
  "part_number": 1,
  "hook_lines": ["DON'T", "OPEN", "IT"],
  "hook_highlight": "OPEN",
  "title_lines": ["THE DOOR", "IS LOCKED"],
  "background_prompt": "dark rainy hallway, glowing phone in wet foreground, amber light behind door"
}
```

| Field | Purpose |
|-------|---------|
| `design_style` | Cover preset id from this guide |
| `series_title` | Top stacked series branding |
| `episode_number` / `part_number` | Badge labels |
| `hook_lines` / `hook_highlight` | Left callout; layout depends on style `hook_style` |
| `title_lines` | Bottom episode title (auto-wrapped from `episode_title` if omitted) |
| `background_prompt` | Episode-specific scene plate appended to the AI prompt (no text in image) |

## Series-level cover config (`series_config.yaml`)

Override template defaults without editing every episode:

```yaml
style_template: thriller_mystery

cover:
  default_design_style: cross_neon_noir
  hook_lines: ["DON'T", "TRUST", "THE CALL"]
  hook_highlight: TRUST
  background_prompt: >
    optional series-wide default scene plate when episodes omit background_prompt
```

Merged with `config/style_templates/<template>.yaml` → `cover` block (series keys override template keys).

## `regenerate_cover.py` reference

Dedicated cover iteration tool. Requires `scenes.json` in the episode folder.

| Flag | Description |
|------|-------------|
| `--series PATH` | Series directory (default: `PIPELINE_SERIES_DIR`) |
| `--episode NAME` | Episode folder (default: `episode_01`) |
| `--list-styles` | Print cover styles for the series `style_template` and exit |
| `--style STYLE_ID` | Use this design style (skips interactive picker) |
| `--compose-only` | Re-run local typography on existing `{slug}_cover_base.png` |
| `--force-background` | Delete/regenerate base background before compose (via `generate_cover(force_cover=True)`) |
| `--save-style` | Write chosen style to `scenes.json` → `cover.design_style` |
| `--cover-provider {fal,openai,local}` | Background provider when generating base (default: `openai`) |
| `--openai-cover` | Shortcut for `--cover-provider openai` |

**Workflow examples**

```bash
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 --compose-only
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 \
  --style horror_frost --force-background --cover-provider fal
python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 \
  --style noir_gold --save-style --compose-only
```

## Background providers

| Provider | Flag | Requirements | Behavior |
|----------|------|--------------|----------|
| **openai** | `--cover-provider openai` or `--openai-cover` | `OPENAI_API_KEY` | GPT Image cover base via `generate_openai_cover_base()` |
| **fal** | `--cover-provider fal` | `FAL_KEY`, `fal_client` | `fal-ai/nano-banana-pro`, portrait 16:9 |
| **local** | `--cover-provider local` | Scene images in `assets/images/` | Uses first suitable scene PNG if AI generation skipped or failed |

If OpenAI is strict (`OPENAI_IMAGE_STRICT`) and generation fails, the tool may fall back to existing episode art or local images. Compositing always runs unless `--compose-only` fails due to a missing base file.

## Visual language principles

- **Same series, new poster** — Reuse one design style (or a small set) so episodes feel like one show; change `background_prompt` and title/hook text per episode.
- **Text-free backgrounds** — Models must not render titles, badges, or logos; all readable text is local for consistency and platform safety.
- **Reserved title zones** — Background prompts ask for negative space in the upper third and a strong foreground prop with glow/reflections.
- **Hook + title hierarchy** — Styles control whether the left hook is handwritten, block, or hidden; highlight one word via `hook_highlight`.
- **Grade matches genre** — Pick a style whose `grade` and `effects` match tone (rain/glitch for neon thriller, soft wash for romance, sepia for western).
- **No gore by default** — Background prompt discourages gratuitous gore unless the scene plate requires it.

## Contributing a new cover style

1. Add a new key under `styles:` in `config/cover_styles.yaml` with `id`, `name`, `description`, `style_templates`, anatomy fields, `colors`, and `effects`.
2. List every `style_template` id where the style should appear in `--list-cover-styles`.
3. Optionally set `default_for_template.<template>` and mirror `default_design_style` in `config/style_templates/<template>.yaml`.
4. Run compose-only on a test base to validate layout:

   ```bash
   python3 tools/regenerate_cover.py --series series/my_series --episode episode_01 \
     --style your_new_style_id --compose-only
   ```

5. Document the id in this file's catalog table.

Implementation lives in `tools/cover_styles.py` (`compose_cover`, `add_poster_grade`, hook/title draw helpers). Keep new layout modes consistent with existing enums unless you extend the Python compositor.
