# Episode 1 Production Checklist

## Before Generating Assets

- Read `script.md`.
- Decide voice: human recording or AI voice.
- Pick one visual generator.
- Use the consistent style prompt from `visual_prompts.md`.
- Create an `assets` folder if needed:

```text
assets/
  voiceover/
  images/
  video/
  music/
  exports/
```

## Generate Visuals

Minimum asset set:
- phone under pillow
- message screen
- Tobi in bed
- morning Lagos street
- Tobi at door
- door knock
- second warning
- woman with package
- package outside door

Quality check:
- no logos
- no public figures
- no unreadable distorted text except where text is not important
- consistent Tobi appearance
- vertical framing or crop-safe composition

## Record or Generate Voiceover

Use the script exactly once, then do one alternate take with slightly more suspense.

Export:

`voiceover_episode_01.mp3`

## Edit

Recommended editor:

CapCut or Descript.

Edit steps:
- Import voiceover first.
- Place visuals to match the timeline in `edit_plan.md`.
- Add captions.
- Add phone buzz, rain, traffic, and knock SFX.
- Add low ambient music.
- Keep final duration over 60 seconds.
- Export 1080x1920.

## Final Review

Before posting:
- Watch without sound. Can the captions carry the story?
- Listen without visuals. Does the narration still work?
- Check the first 3 seconds. Is the hook immediate?
- Check the ending. Does it force episode 2 curiosity?
- Confirm description says fictional story.

## Output Names

```text
exports/episode_01_tiktok.mp4
exports/episode_01_youtube_shorts.mp4
exports/episode_01_cover.png
```
